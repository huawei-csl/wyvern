1 Introduction

1.1 Overview of State-Space Models

State-Space Models (SSMs) are a class of machine learning algorithms designed to model dynamic systems by describing how their internal state evolves over time through differential equations. These models are rooted in control theory and system identification, and they have been widely applied in fields such as economics, neuroscience, ecology, and weather forecasting [1, IBM - State Space Model]. SSMs are characterized by their ability to capture temporal dependencies in sequential data, making them particularly suitable for tasks like time-series forecasting, natural language processing, and audio analysis. The core mathematical foundation of SSMs involves two key equations: the state equation, which describes the evolution of the internal state, and the output equation, which maps the state to observable outputs. These equations are parameterized by matrices A, B, C, and D, which represent the relationships between state variables, inputs, and outputs [1, IBM - State Space Model]. SSMs can be discretized using techniques like the Zero-order hold, allowing them to handle discrete sequences effectively [2, Maarten Grootendorst - Mamba and State Space Models]. The recurrent and convolutional representations of SSMs highlight their respective advantages and limitations, offering flexibility in computational and modeling needs [3, StanfordBlog - S4].

1.2 Historical Context and Applications

The origins of SSMs can be traced back to control systems engineering, where they were used to model and control dynamic systems. Over time, SSMs have been adapted for machine learning applications, particularly in sequence modeling. SSMs have been successfully applied in various domains, including natural language processing, robotics, autonomous vehicles, and edge computing systems [5, Quamba]. Their ability to handle long sequences efficiently has made them a viable alternative to traditional models like Recurrent Neural Networks (RNNs) and Transformers [6, Mamba-SSM]. Techniques like HiPPO (High-order Polynomial Projection Operators) have been introduced to improve the handling of long sequences and training efficiency in SSMs [1, IBM - State Space Model].

State-space models (SSMs) are rooted in control theory and system identification, where they are used to describe the evolution of dynamic systems over time. In their continuous-time formulation, SSMs are governed by linear ordinary differential equations (ODEs) that describe how the internal state of a system evolves in response to an input signal. This discretization process involves sampling the continuous state at specific time steps, effectively transforming the SSM into a sequence-to-sequence model akin to recurrent neural networks (RNNs) [1, IBM - State Space Model] [3, StanfordBlog - S4]. 3.2 Discretization Techniques

Discretization is a critical step in adapting continuous-time SSMs to discrete sequences, such as text or time series data. Two primary methods are commonly used: the zero-order hold (ZOH) method and the bilinear transformation.

3.2.1 Zero-Order Hold Method

The zero-order hold method assumes that the input signal u(t)u(t) remains constant between discrete time steps. This approximation allows the continuous-time state equation to be transformed into a discrete-time recurrence relation. The discretized state equation becomes:

The bilinear transformation, also known as Tustin’s method, offers a more accurate discretization by approximating the continuous-time system using a trapezoidal rule. This method maps the continuous-time system to the discrete-time domain using the following transformation:

where ss is the Laplace variable, zz is the Z-transform variable, and TT is the sampling period. The bilinear transformation preserves the stability and frequency response of the original system, making it a preferred choice for many applications [3, StanfordBlog - S4] [11, SSD Algorithm - Mamba2]. 8 Model Compression Techniques

Model compression techniques are essential for deploying state-space models (SSMs), particularly Mamba models, in resource-constrained environments such as edge devices or cloud-based services. These techniques aim to reduce the computational and memory requirements of models while maintaining their performance. This section explores four key approaches to model compression: structured pruning, low-rank approximation, control-theoretic compression, and knowledge distillation.

8.1 Structured Pruning

Structured pruning involves removing entire structures, such as neurons, filters, or layers, from a neural network to reduce its size and complexity. This technique can be combined with other compression methods, such as quantization, to further optimize model performance [18, Q-Mamba]. Additionally, Mamba’s selective scan algorithm leverages hardware-aware optimizations to minimize data transfer between memory types, enhancing computational efficiency [2, Maarten Grootendorst - Mamba and State Space Models].

8.2 Low-Rank Approximation

Low-rank approximation techniques aim to reduce the redundancy in neural networks by approximating layers with fewer, lower-rank filters. This approach is particularly useful for compressing high-dimensional matrices in various neural network architectures, making them more suitable for deployment on resource-constrained hardware [28, Medium - Model Compression Techniques for Deep Learning in Space]. Furthermore, the Structured State Space Duality (SSD) layer in Mamba-2 leverages matrix multiplications to improve training efficiency [15, SSD-Mamba2].

8.3 Control-Theoretic Compression

Control-theoretic compression leverages principles from control theory to compress state-space models. One such approach is Hankel singular value analysis, which measures the energy of each state and performs balanced truncation to reduce the model’s size while preserving its performance. Control-theoretic compression is particularly effective for linear time-invariant SSMs, such as Mamba models, as it preserves task-critical structure that would otherwise be lost [29, Sakamoto-Sato MOR]. Additionally, the HiPPO (High-order Polynomial Projection Operators) technique, used in Mamba models, improves long-term memory handling by initializing the state matrices with orthogonal polynomials [8, Mamba-SSM].

8.4 Knowledge Distillation

Knowledge distillation involves transferring knowledge from a large, complex model (teacher) to a smaller, simpler model (student). While distillation techniques have been experimentally applied to Mamba models, they did not yield significant advantages, as quantization or uncompressed Mamba models proved more efficient for deployment in resource-constrained environments [30, Suwannaphong - TinyML Indoor Localisation]. Additionally, hybrid architectures like StableMamba, which interleave Mamba blocks with Transformer blocks, enhance scalability and robustness without relying on distillation, further optimizing performance [24, StableMamba].

In conclusion, model compression techniques are crucial for optimizing Mamba models for deployment in resource-constrained environments. Structured pruning, low-rank approximation, control-theoretic compression, and knowledge distillation each offer unique advantages in reducing model size and computational complexity while maintaining performance. These techniques can be combined to achieve even greater efficiency, making Mamba models more accessible for a wide range of applications.

12.2 MambaQuant

MambaQuant is a post-training quantization (PTQ) framework designed specifically for Mamba series models. It addresses key challenges in quantizing Mamba models, such as substantial outliers in gate projections, output projections, and matrix multiplications, as well as the amplification of these outliers by Mamba’s unique parallel scan operation (PScan). MambaQuant introduces two main techniques: enhanced rotation based on the Karhunen-Loève transform (KLT) and smoothed fused rotation. These techniques align the maxima and variances of quantized data across channels, enabling high-accuracy quantization with less than 1% accuracy loss for W8A8 quantization across various benchmarks [34, MambaQuant].

12.3 PTQ4VM

PTQ4VM (Post-Training Quantization for Visual Mamba) is a novel quantization technique designed to address the unique challenges of quantizing Visual Mamba models. Visual Mamba processes image tokens sequentially in a fixed order, introducing specific quantization challenges such as token-wise variance, channel-wise outliers, and long-tailed activation distributions. PTQ4VM mitigates these challenges through per-token static (PTS) quantization and joint learning of smoothing scale and step size (JLSS). This approach achieves up to 1.83x speedup on GPUs with negligible accuracy loss compared to FP16, making it highly effective for visual tasks [21, PTQ4VM].

12.4 Q-Mamba

Q-Mamba is a quantization framework that optimizes Mamba models by reducing memory consumption during the token generation phase. It introduces two key techniques: Decoupled Scale Quantization (DSQ) and Efficient Selectivity Reconstruction (ESR). DSQ mitigates outliers in both state and channel dimensions by applying separate quantization scales, while ESR simulates quantization errors by quantizing only the final timestep during training. As shown in Figure 14, this methodology integrates token generation with state caching and ESR implementation to preserve selective abilities in quantized models.

Q-Mamba achieves a 50% reduction in memory consumption for Mamba2-2.7B with W8A8H4 quantization, with only a 2.13% average accuracy degradation on zero-shot tasks [18, Q-Mamba].

12.5 Q-S5

Q-S5 explores the impact of quantization on State Space Models (SSMs), specifically focusing on the S5 model. As illustrated in Figure 15, the S5 model architecture has been adapted for quantization experiments within the Q-S5 framework, including the replacement of normalization operations and the GELU activation function with their quantized variants.

See Fig. 1 in reference [19, Q-S5]

Figure 15. Architecture of the S5 model adapted for quantization in the Q-S5 framework, showing the replacement of normalization and GELU activation with quantized variants.

It employs Quantization-Aware Training (QAT) and Post-Training Quantization (PTQ) to systematically evaluate quantization sensitivity across various tasks. Q-S5 maintains test accuracy within 1% of the full-precision model on Sequential MNIST (sMNIST) and most Long Range Arena (LRA) tasks. However, performance degrades significantly for recurrent weights below 8-bit precision, highlighting the need for QAT in most tasks beyond language-based LRA tasks [19, Q-S5].

12.6 QS4D

QS4D (Quantization-aware training for efficient hardware deployment of structured state-space sequential models) applies QAT to structured state-space models (SSMs), focusing on the S4D model. It quantizes various components of the model, including the state transition matrix, time steps, and activation signals, using a ladder of integer values. QS4D enables aggressive quantization down to 6 bits for all model parameters on the sequential CIFAR10 benchmark, reducing computational complexity by up to 11.5 times and memory footprint by up to 2.9 times compared to PTQ. It also enhances the model’s resilience to transient noise, making it suitable for edge-computing hardware [23, QS4D].

12.7 StableMamba

StableMamba addresses the scalability and robustness challenges of Mamba-based state-space models (SSMs) in vision tasks by interleaving Mamba blocks with Transformer blocks. This hybrid architecture enhances scalability and robustness without relying on knowledge distillation. StableMamba demonstrates significant improvements over VideoMamba and other state-of-the-art models, achieving up to +1.7% accuracy improvement on ImageNet-1K and superior robustness to common corruptions [25, StableMamba].

12.8 CompreSSM

CompreSSM is a control-theoretic approach to compressing State Space Models (SSMs) during training. It leverages Hankel singular value analysis to measure the energy of each state and perform balanced truncation of the original system to a smaller representation with performance guarantees. CompreSSM accelerates optimization while preserving expressivity, retaining task-critical structure that is lost by models trained directly at smaller dimensions [36, CompreSSM].

12.9 Sakamoto-Sato MOR

Sakamoto-Sato MOR (Model Order Reduction) proposes a compression method for deep state-space models (Deep SSMs) that incorporates linear-quadratic-output (LQO) systems. As illustrated in Figure 16, this approach fundamentally differs from conventional model order reduction techniques by holistically accounting for inter-layer interactions and nonlinear components within the Deep SSM architecture, rather than compressing individual linear time-invariant (LTI) subsystems in isolation.

See Fig. 1 in reference [29, Sakamoto-Sato MOR]

It derives a provable upper bound on the output error by minimizing the H₂-error norms between the layerwise LQO systems. This method achieves a significant reduction in trainable parameters (approximately 80%) with only a 4-5% performance drop, making it suitable for resource-constrained settings [29, Sakamoto-Sato MOR].

12.10 LightMamba

LightMamba is an efficient FPGA-based acceleration framework for Mamba state-space models (SSMs). The overall architecture and key components of LightMamba are depicted in Figure 17, which includes specialized hardware units designed for efficient computation and quantization.

It employs a rotation-assisted post-training quantization (PTQ) algorithm to mitigate scattered activation outliers and introduces Power-of-Two (PoT) quantization for the SSM layer. LightMamba achieves negligible accuracy loss with 8-bit quantization and outperforms prior methods in 4-bit quantization, achieving 7.21 tokens/s on Xilinx VCK190 FPGA [16, LightMamba].

12.11 PROMPTCOT-MAMBA

PROMPTCOT-MAMBA is an attention-free language model that leverages Mamba-2’s selective state space dual (SSD) layers to replace traditional self-attention mechanisms. It enables constant-time inference and fixed memory consumption per token, eliminating the need for key-value caching. PROMPTCOT-MAMBA outperforms Transformer and hybrid Mamba-Transformer models of comparable size across multiple benchmarks, showcasing its strong reasoning capabilities [26, PROMPTCOT-MAMBA].
